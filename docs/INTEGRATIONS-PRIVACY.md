# Integration and SDK privacy inventory

## November 7: local facilitation of external sources

External sources now support local PESO requests; they are not live agency API integrations. Source links remain evidence while requests, verification, referral/enrollment progress and follow-up stay in Laravel. Profiles are not automatically sent to an external source when a request is created. PESO must coordinate the employer/provider and record actual evidence. Local intake verification notes are hidden from public program JSON. Existing notices, role/ownership checks, private document controls and human decisions remain.

Catalog/request removal preserves linked history through soft deletion; administrator account erasure retains the existing personal-data cascade and requires password confirmation and a five-second server intent. No real account or workflow record was removed during implementation. See [workflow and deletion contract](WORKSPACE-UPDATE-2026-11-07.md).

Reviewed 13 October 2026 against the active React router/import graph, Laravel routes/services, browser requests, local storage/service worker and Android source. This records current technical behavior. The eventual operator must verify hosting contracts, processor locations, access controls and any cross-border processing before production.
